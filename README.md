# Sunflower Data Analysis
This repository contains data and analyses from a sunflower experiment investigating growth and physiological responses of different sunflower genotypes under different temperature treatments.
## Repository structure
- `Data/Raw/` – original experimental data
- `Data/Processed/` – datasets generated during data processing
- `Scripts/` – R scripts used for data analysis
- `Figures/` – figures generated during the analysis
- `Results/` – statistical results and output tables
- `Reports/` – course activities and final reports
## Project status
The project is currently under development as part of the course activities.
